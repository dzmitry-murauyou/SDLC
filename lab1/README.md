# Калькулятор счастья 🙂

Приложение на Java (Swing): пользователь вводит **сон, кофе, общение и работу — за сутки**,
а **выходные — за неделю**, программа рассчитывает **индекс счастья (0–100)** и выдаёт рекомендацию:
**поспать**, **уволиться** или **купить пиццу**.

Каркас — **MVC с активной моделью**: модель сама оповещает представления об изменениях (паттерн «Наблюдатель»,
`PropertyChangeSupport`).

## Что вводит пользователь

| Поле | Единица | Диапазон | Тип |
|---|---|---|---|
| Сон | часов **в сутки** | 0–24 | дробное |
| Кофе | чашек **в сутки** | 0–20 | целое |
| Приятное общение | **минут в сутки** | 0–1440 | целое |
| Работа | часов **в сутки** | 0–**24** (ввод не ограничен) | дробное |
| Выходные | дней **в неделю** | 0–7 | целое |

> ⚠️ Общение — это **приятное** время с друзьями и близкими, рабочие разговоры в него не входят,
> поэтому оно вводится отдельно и в минутах.

```
┌──────────── Ввод данных: сутки и выходные ────────────┐
│ Сон, часов в сутки (0–24, можно дробное):             │
│ [ 8 ]                                                 │
│ Меньше 6 часов — 0 баллов, полный балл — с 8 часов    │
│ и выше.                                               │
│                                                       │
│ Кофе, чашек в сутки (0–20, целое):                    │
│ [ 2 ]                                                 │
│ 1–2 чашки — максимум, 0 чашек — половина балла,       │
│ с 5-й — 0.                                            │
│                                                       │
│ Приятное общение, минут в сутки (0–1440, целое):      │
│ [ 60 ]                                                │
│ Только отдых с друзьями и близкими — рабочие          │
│ разговоры не считаются.                               │
│                                                       │
│ Работа, часов в сутки (0–24, можно дробное):          │
│ [ 8 ]                                                 │
│ Полный балл — до 8 часов, с 8 до 12 — падает,         │
│ после 12 — 0.                                         │
│                                                       │
│ Выходные, дней в неделю (0–7, целое):                 │
│ [ 2 ]                                                 │
│ В неделю: 0 дней — 0 баллов, 1 — половина,            │
│ 2 — 75 %, 3+ — максимум.                              │
│                                                       │
│   Сон + работа + общение не могут превышать 24 часа   │
│   в сутки — иначе появится ошибка.                    │
│                    [ OK ]  [ Отмена ]                 │
└───────────────────────────────────────────────────────┘
```

**Главная форма** — результат (индекс + рекомендация + расшифровка баллов) и кнопка **«Ввести данные»**:

```
┌──────────────────── Калькулятор счастья ────────────────────┐
│                     Калькулятор счастья                      │
│  Сон: 8 ч/сутки • Кофе: 2 чашек/сутки • Приятное общение:    │
│  60 мин/сутки                                                │
│  Работа: 8 ч/сутки • Выходные: 2 дн/неделю                   │
│               Индекс счастья: 85.0 из 100                    │
│   Рекомендация: Купить пиццу и наслаждаться жизнью! ...      │
│  Баллы: сон 30.0/30 • кофе 10.0/10 • общение 10.0/20 ...     │
│                   [ Ввести данные ]                          │
└──────────────────────────────────────────────────────────────┘
```

При повторном открытии диалога поля заполняются **последними введёнными данными** (модель их запоминает).
Некорректный ввод → окно «Ошибка ввода», после чего диалог открывается снова **с сохранённым набранным текстом**.

## Проверка ввода

1. **Буквы не пропускаются уже при наборе**: на каждом поле стоит `NumericDocumentFilter` —
   цифры и (для дробных полей) один разделитель `.` или `,`. Попытка напечатать букву
   подсвечивается сообщением «Только цифры!» под формой.
2. **Полная перепроверка при нажатии «OK»** (делает контроллер): пустое поле, буквы,
   «мусор» вроде `1.2.3`, `-5`, `1e2`, `999999999999`, выход за диапазон.
3. **Правило 24 часов**: `сон + работа + общение(мин/60)` не может превышать 24 часа в сутки.
   Иначе ошибка с расшифровкой, например:

   > В сутках всего 24 часа, а у вас получилось 25.0 ч: сон 10.0 ч + работа 12.0 ч
   > + общение 180 мин (3.0 ч). Уменьшите одно из значений.

   Ровно 24 часа — можно.

Дробные числа можно писать и через точку, и через запятую (`7.5` / `7,5`).

## Формула индекса счастья (0–100)

| Фактор | Баллы | Правило |
|---|---|---|
| Сон, ч/сутки | до 30 | **8+ часов** — полный балл (больше 8 — без потери баллов); 6–8 часов — линейный рост от 0; **< 6 часов → 0** |
| Кофе, чашек/сутки | до 10 | **1–2 чашки** — полный балл; 0 чашек → половина балла; 3–4 — линейное снижение (3 → 6.7, 4 → 3.3); **с 5-й → 0** |
| Общение, мин/сутки | до 20 | растёт пропорционально до **120 минут**, дальше — полный балл |
| Работа, ч/сутки | до 20 | до 8 часов — полный балл, от 8 до **12** линейно падает до 0; меньше 2 часов → 70 % балла; ввод работы не ограничен |
| Выходные, дн/неделю | до 20 | **3+ дня** — полный балл, 2 дня → 75 %, 1 день → 50 %, 0 дней → 0 |

Примеры расчёта:

| Вход (сон / кофе / общение / работа / выходные) | Индекс |
|---|---|
| 8 ч / 2 / 120 мин / 8 ч / 3 дн | **100.0** |
| 8 ч / 2 / 60 мин / 8 ч / 2 дн | **85.0** |
| 7 ч / 3 / 45 мин / 10 ч / 1 дн | **49.2** |
| 5 ч / 5 / 30 мин / 12 ч / 0 дн | **5.0** |

Рекомендация (проверяется по порядку):

- сон **< 6 ч/сутки** → **«Поспать!»** (недосып — главный враг счастья);
- иначе работа **> 10 ч/сутки** → **«Уволиться!»** (переработка, предел 12 часов);
- иначе **0 выходных** → «Купить пиццу — и договориться хотя бы об одном выходном!»;
- иначе кофе **> 3 чашек** → «Купить пиццу и заменить часть кофе водой»;
- иначе → **«Купить пиццу!»** (оттенок зависит от индекса: ≥70 — «всё отлично», 40–69 — «неплохо», <40 — «срочно себя порадовать»).

Все пороги и веса вынесены в константы `HappinessModel` (`SLEEP_ZERO_HOURS`, `SLEEP_FULL_HOURS`,
`COFFEE_ZERO_CUPS`, `ENOUGH_SOCIAL_MINUTES`, `HARD_WORK_HOURS`, `ENOUGH_WEEKEND_DAYS` и т. д.) — формулу легко подкрутить.

## Требования

- **JDK 17+** (код простой и соберётся даже на Java 8 — тогда поменяйте `17` на `8` в `pom.xml`);
- **IntelliJ IDEA** (подойдёт бесплатная Community Edition);
- Maven ставить отдельно не нужно — в IDEA он встроенный.

## Как открыть проект в IntelliJ IDEA (вариант 1 — через Maven, рекомендуется)

1. `File → Open…` и выберите папку проекта (ту, где лежит `pom.xml`), нажмите `Open`.
2. Если IDEA предложит `Open as Project` — согласитесь; при вопросе о доверии — `Trust Project`.
3. Дождитесь, пока IDEA скачает зависимости (строка прогресса внизу справа).
4. Если попросит выбрать JDK — укажите JDK 17+ (`File → Project Structure… → Project → SDK`).

Запуск:

- через Maven: `Run → Run… → Main` (или откройте `src/main/java/com/example/happiness/Main.java` и нажмите ▶️ слева от `main`);
- либо из терминала: `mvn -q compile exec:java` — но проще кнопкой ▶️ в IDEA.

Сборка jar: `mvn package` → запуск `java -jar target/happiness-calculator-1.1.0.jar`.

## Как открыть как обычный проект IDEA без Maven (вариант 2)

1. `File → New → Project from Existing Sources…` → выберите папку проекта.
2. Выберите `Create project from existing sources` → `Next`.
3. Укажите `Project SDK` (JDK 17+) → `Next` → `Finish`.
4. Пометьте `src/main/java` как `Sources Root` (правый клик → `Mark Directory as`).
5. Откройте `Main.java` и запустите ▶️.

Либо вообще без IDEA — скриптами `run.sh` (Linux/macOS) / `run.bat` (Windows), нужен только JDK:
`sh run.sh`.

> 💡 В Linux для Swing-окон нужен графический сеанс. Если запускаете через SSH/WSL без X-сервера,
> включите проброс X11 или запускайте на машине с рабочим столом.

## Структура MVC с активной моделью

```
com.example.happiness
├── Main.java                  точка входа: создаёт Model + View + Controller, подписывает View на Model
├── model                      МОДЕЛЬ (активная: сама рассылает события через PropertyChangeSupport)
│   ├── HappinessData.java     входные данные: сутки (сон, кофе, общение, работа) + выходные в неделю,
│   │                          проверка диапазонов и правила «не больше 24 часов в сутки»
│   ├── HappinessResult.java   результат (индекс + рекомендация + расшифровка баллов)
│   └── HappinessModel.java    хранение данных, формула расчёта, события PROP_DATA / PROP_RESULT
├── view                       ПРЕДСТАВЛЕНИЯ (только показывают, логики расчёта не содержат)
│   ├── MainFrame.java         главная форма: результат + кнопка «Ввести данные», слушатель модели
│   ├── InputDialog.java       модальное окно ввода, восстанавливает последние данные
│   └── NumericDocumentFilter.java  фильтр «только цифры» для полей ввода (буквы не печатаются)
└── controller                 КОНТРОЛЛЕР
    └── HappinessController.java  открывает диалог, парсит/проверяет ввод (буквы, диапазоны, 24 часа),
                                 кладёт данные в модель, показывает ошибки
```

Схема взаимодействия:

```
┌──────────┐  нажал кнопку   ┌────────────┐  setData()   ┌───────────┐
│ MainFrame │ ─────────────▶ │ Controller │ ───────────▶ │   Model   │
│  (View)   │                │            │              │ (активная)│
└──────────┘                └────────────┘              └─────┬─────┘
      ▲                                                      │ событие PROP_RESULT
      └──────────────────────────────────────────────────────┘
                    View обновляется само (Observer)
```
