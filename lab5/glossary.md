# Глоссарий Guardian — лабораторная работа №5

| Термин | Определение в проекте |
|---|---|
| Guardian | Локальное настольное приложение Windows для защиты паролей и предоставленных пользователем данных криптокошельков. |
| Пользователь | Основной актёр; владелец локального хранилища, который создаёт, открывает и блокирует его, а также управляет записями. |
| Хранилище (Vault) | Локальный набор записей Guardian, доступ к которому разрешается после успешной аутентификации. |
| Заблокированное хранилище | Состояние, в котором интерфейс не предоставляет доступ к расшифрованным секретам. |
| Разблокированное хранилище | Состояние после проверки мастер-пароля и зарегистрированного USB-ключа FIDO2/WebAuthn. |
| Мастер-пароль | Секрет, который пользователь вводит для доступа к хранилищу; не сохраняется в открытом виде. |
| FIDO2/WebAuthn | Механизм аппаратной аутентификации, использующий зарегистрированный USB-ключ безопасности. |
| Запись | Элемент хранилища с названием, логином, паролем, адресом источника и дополнительными полями. |
| Wallet-data | Метаданные криптокошелька и предоставленная пользователем seed-фраза либо приватный ключ; хранится локально в зашифрованном виде. |
| Seed-фраза | Предоставленный пользователем секрет восстановления кошелька; в Guardian не генерируется и скрыт по умолчанию. |
| Приватный ключ | Предоставленный пользователем секрет доступа к криптокошельку; Guardian его не создаёт и не использует для транзакций. |
| Явное раскрытие | Отдельное действие пользователя, после которого секрет может быть временно показан в интерфейсе. |
| Буфер обмена | Системный механизм временного копирования; очистка при блокировке выполняется, если это позволяет Windows. |
| TOTP | Одноразовый код на основе времени и секрета внешнего сервиса; не является вторым фактором разблокировки самого Guardian. |
| Автозаполнение | Явно инициированная передача выбранных пользователем полей в проверенный контекст браузера. |
| Источник | Схема, имя хоста и эффективный порт адреса, с которым сопоставляется запись перед автозаполнением. |
| Резервная копия | Ручной экспорт локального хранилища в собственный зашифрованный формат Guardian. |
| Восстановление | Проверка выбранной копии и перенос её данных в другой экземпляр Guardian без обхода обязательной аутентификации. |
| UML | Унифицированный графический язык моделирования структуры и поведения программных систем. |
| Прецедент (Use Case) | Описание цели актёра и наблюдаемого поведения системы в основном и альтернативных потоках. |
| Актёр (Actor) | Пользователь, устройство или внешняя система за границей Guardian, взаимодействующие с ним в определённой роли. |
| SRS | Спецификация системных/программных требований; определяет, что должна делать система. |
| SDD | Описание проектирования ПО; определяет проектные представления и их связь с требованиями. |
| ADR | Запись архитектурного решения с контекстом, вариантами, решением и последствиями. |
| Change-01 | Учебный сценарий ЛР №4 о регистрации запасного FIDO2-ключа; не входит в базовый SRS до отдельного согласования. |
