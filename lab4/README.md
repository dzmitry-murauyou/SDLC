# Лабораторная работа №4 — системные требования Guardian

Материалы продолжают SRS Guardian из предыдущего этапа. Область релиза 1.0 включает локальное зашифрованное хранение пользовательских данных криптокошельков (seed-фраз/приватных ключей) и ручное раскрытие/копирование; операции с блокчейном не входят. Способ внутренней интеграции кошелька в приложение остаётся открытым.

## Важное замечание об оценках

Учебная история планов: V1 — 10 недель/168 ч-д; V2 после раунда 1 — цель 8 недель/168 ч-д; V3 после раунда 2 — запасной FIDO2-ключ (+10 ч-д), итого 178 ч-д при цели 8 недель, если доступны junior и senior reviewer. Фиксированная сумма для сценария — **20 000 BYN**; её задал пользователь, она не рассчитана по ставкам и не является фактическим согласием заказчика. Даты старта/релиза и доступность ресурсов не утверждены. Реплики в `planning/customer-negotiation.md` вымышлены; Change-01 не добавлен в базовый SRS. Открытые решения из SRS (например, матрица браузеров, восстановление при утрате всех зарегистрированных USB-ключей, JDK, криптографические параметры и интеграция wallet-data как типа записи или отдельного модуля) не выдаются за утверждённые.
