# Лабораторная работа №4 — системные требования Guardian

Материалы продолжают SRS Guardian из предыдущего этапа. Область релиза 1.0 включает локальное зашифрованное хранение пользовательских данных криптокошельков (seed-фраз/приватных ключей) и ручное раскрытие/копирование; операции с блокчейном не входят. Способ внутренней интеграции кошелька в приложение остаётся открытым.

## Важное замечание об оценках

Базовый относительный план — 10 недель; в учебном сценарии переговоров рассматривается цель 8 недель при подтверждении примерно на 25% большей доступной мощности команды. Оценка — 168 человеко-дней; даты старта/релиза, команда и бюджет не утверждены. Сценарные реплики заказчика в `planning/customer-negotiation.md` вымышлены и не являются фактическим согласованием. Неопределённые решения из SRS (например, матрица браузеров, процедура восстановления после утраты USB-ключа, JDK, криптографические параметры и интеграция данных кошелька как типа записи или отдельного модуля) не выдаются за уже утверждённые.
