# Лабораторная работа №4 — системные требования Guardian

Материалы продолжают SRS Guardian из предыдущего этапа. Область релиза 1.0 включает локальное зашифрованное хранение пользовательских данных криптокошельков (seed-фраз/приватных ключей) и ручное раскрытие/копирование; операции с блокчейном не входят. Способ внутренней интеграции кошелька в приложение остаётся открытым.

## Важное замечание об оценках

Календарный срок, бюджет и ставки в плановых документах пока не заданы; оценка дана в человеко-днях и не является коммерческим предложением. Черновик первого сообщения подготовлен, но переписка и ответ заказчика ещё не заполнены. Неопределённые решения из SRS (например, матрица браузеров, процедура восстановления после утраты USB-ключа, JDK, криптографические параметры и интеграция данных кошелька как типа записи или отдельного модуля) не выдаются за уже утверждённые.
