# Калькулятор счастья

**Дисциплина:** Жизненный цикл разработки программного обеспечения
**Специальность:** 6-05-0611-05 «Компьютерная инженерия»
**Вариант:** 23

## Описание проекта

Приложение **«Калькулятор счастья»** на языке Java с графическим интерфейсом
(Swing). Принимает пять параметров и вычисляет индекс счастья по
стобалльной шкале с выдачей рекомендации.

Входные параметры:

- количество сна (часов в сутки),
- кофе (чашек в сутки),
- приятное общение (минут в сутки),
- работа (часов в сутки),
- выходные (дней в неделю).

Итоговый индекс складывается из баллов по пяти факторам:

| Фактор    | Максимум баллов |
|-----------|-----------------|
| Сон       | 30              |
| Кофе      | 10              |
| Общение   | 20              |
| Работа    | 20              |
| Выходные  | 20              |
| **Итого** | **100**         |

По результату формируется одна из рекомендаций: **«поспать»**,
**«уволиться»** или **«купить пиццу»**.

## Архитектура

Проект построен по паттерну **MVC с активной моделью**.

- **Model** — `HappinessModel` хранит данные и результат расчёта, содержит
  бизнес-логику вычисления индекса счастья и уведомляет подписчиков через
  `PropertyChangeSupport` (паттерн «Наблюдатель»).
- **View** — `MainFrame` отображает данные и результат, реализует
  `PropertyChangeListener` и обновляется автоматически при изменении модели.
  `InputDialog` — модальное окно ввода пяти параметров.
- **Controller** — `HappinessController` обрабатывает ввод пользователя,
  выполняет парсинг строк в числа, проверяет корректность и передаёт данные
  в модель.

Дополнительные классы:

- `HappinessData` — неизменяемый класс входных данных, проверяет диапазоны
  и правило «сон + работа + общение ≤ 24 часов».
- `HappinessResult` — неизменяемый класс результата: индекс, рекомендация
  и баллы по каждому фактору.
- `Main` — точка входа, связывает представление с активной моделью через
  `addPropertyChangeListener`.
